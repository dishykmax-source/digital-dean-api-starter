# Практична робота №3 — Асиметричне та гібридне шифрування

**Здобувач освіти:** ____________________  
**Група:** ____________________  
**Номер у списку:** 7  
**Варіант:** 3 — поле `summary` у відповіді API.

## Мета
Дослідити RSA-OAEP, навчальну гібридну схему RSA-3072 + AES-256-GCM та HPKE Base X25519/P-256; інтегрувати результати експерименту в API «Цифровий деканат».

## Реалізація
Реалізовано п'ять профілів, єдиний інтерфейс генерації ключів/шифрування/розшифрування, контроль формату конвертів і єдину помилку `DecryptionError`. Контекст: `digital-dean:practice-03:report-v1`.

## Індивідуальний варіант
У відповіді `GET /api/v1/lab/crypto/asymmetric-benchmark-results` додано обов'язковий об'єкт `summary`: `key_profiles_count`, `results_count`, `checks_count`, `all_checks_passed`. Він обчислюється із збереженого звіту; повторний експеримент під час HTTP-запиту не запускається.

## Експеримент
Заповнити після локального запуску `python -m benchmarks.asymmetric_benchmark`. Вставити параметри середовища, `run_id`, таблицю медіан/IQR, два графіки та аналіз. Не підставляти демонстраційні чи вигадані значення.

## Перевірки
Очікується 22 реальні перевірки: 5 roundtrip, 5 wrong_key, 5 tamper, 5 wrong_context та 2 OAEP boundary. Додати фактичний результат `pytest`.

## Висновок
Порівнювати RSA-профілі тільки між собою на 64 байтах, а гібридні профілі — на однакових розмірах 1 KiB, 64 KiB та 1 MiB. Експеримент вимірює швидкодію, а не криптографічну стійкість.
