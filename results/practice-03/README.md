# Результати практичної №3

Запустіть `python -m benchmarks.asymmetric_benchmark` у середовищі з `cryptography==48.0.1`. Команда виконує реальні криптографічні перевірки, вимірювання та атомарно створює `raw.csv` і `report.json`. Після цього виконайте `python -m benchmarks.plot_asymmetric_results` для побудови графіків.

Файли вимірювань навмисно не підмінено шаблонними числами: їх потрібно отримати на машині, де встановлено потрібну версію бібліотеки HPKE.
